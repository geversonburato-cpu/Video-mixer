VIDEO MIXER — PWA COMPLETA

Arquivos:
- index.html: aplicativo
- manifest.webmanifest: instalação PWA
- sw.js: cache/offline da interface
- ícones

Como publicar:
1. Crie um repositório público no GitHub.
2. Envie estes arquivos para a raiz do repositório.
3. Ative GitHub Pages usando Deploy from a branch / branch main / root.
4. Aguarde a publicação.
5. Abra a URL HTTPS no Chrome do Android.
6. Use o menu do Chrome > Adicionar à tela inicial / Instalar aplicativo.

Observação: FFmpeg e JSZip são carregados de CDNs (jsDelivr). Para produção, o ideal é fixar e hospedar localmente essas dependências ou usar um build.
